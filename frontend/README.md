# LLBox AI Command Center

Enterprise Smart Locker & AI Operations admin portal (Next.js App Router).

## Requirements
- Node.js 18+ (LTS recommended)
- npm 9+

## Setup
```bash
npm install
npm run dev
```

App runs at http://localhost:3000

## Scripts
- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — start production server
- `npm run lint` — ESLint
